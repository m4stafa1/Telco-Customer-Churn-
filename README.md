# Customer Churn Prediction

## Overview
This project focuses on predicting customer churn using both Machine Learning and Deep Learning techniques. The workflow includes data exploration, preprocessing, handling class imbalance, model training, and performance comparison.

## Dataset
- Telco Customer Churn Dataset
- Binary Classification Problem
- Target: `Churn`

---

## Project Workflow

- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Feature Encoding
- Feature Scaling
- Handling Class Imbalance
- Model Training
- Performance Evaluation
- Machine Learning vs Deep Learning Comparison

---

## Models Implemented

### Machine Learning
- Logistic Regression
- Support Vector Machine (SVM)

### Deep Learning
- Artificial Neural Network (ANN)

Architecture:

Input Layer
→ Dense + ReLU
→ Dense + ReLU
→ Output Layer (Sigmoid)

---

## Results

| Model | Accuracy |
|--------|----------|
| Logistic Regression | **78%** |
| SVM | Lower than Logistic Regression |
| ANN (Deep Learning) | **79%** |

The ANN achieved the best overall performance, slightly outperforming the traditional Machine Learning models.
